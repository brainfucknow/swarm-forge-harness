# SwarmForge Constitution

This file takes precedence over article files. Read and obey every file in
`swarmforge/constitution/articles/`:

- `engineering.md`: language defaults, testability, acceptance pipeline, verification.
- `workflow.md`: task worktrees, commits, scratch files, failure conditions.
- `handoffs.md`: how roles pass work through git-bug tasks.
- `project.md`: this project's pack, language, and ownership boundaries.

Then read `swarmforge/roles/<your role>.md`.
